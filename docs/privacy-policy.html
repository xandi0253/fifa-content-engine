Política de Privacidade — FIFA Content Engine

Última atualização: setembro de 2026

O FIFA Content Engine é uma ferramenta de uso pessoal criada para automatizar a edição e publicação de clipes de gameplay em plataformas de vídeo, operada e utilizada exclusivamente pelo próprio desenvolvedor/proprietário da conta.

Quais dados são acessados

Esta ferramenta acessa a API de Dados do YouTube (YouTube Data API v3) exclusivamente para publicar vídeos na própria conta do usuário que autoriza o acesso, e para consultar estatísticas públicas (visualizações, curtidas, comentários) dos vídeos publicados por essa mesma conta.

Como os dados são usados

Os dados acessados via OAuth (upload de vídeo, gerenciamento de visibilidade, leitura de estatísticas) são usados apenas para operar o pipeline de publicação de conteúdo do próprio usuário. Nenhum dado é compartilhado, vendido ou repassado a terceiros.

Armazenamento

O token de acesso OAuth é armazenado localmente, apenas no computador do usuário que executa a ferramenta, e nunca é transmitido a servidores de terceiros.
